Privacy policy

Last updated: October 23, 2026

This policy covers the Google OAuth app "rclone" owned by Miguel Martinez (migmar70). The app is for the owner's personal use only: it lets the open-source program rclone on the owner's own computer read and write the owner's own Google Drive.

What data is accessed

Files and folders in the signed-in Google account's Google Drive, using the Google Drive API scopes drive, docs and drive.metadata.readonly.

How it is used and stored

  • Data is transferred only between Google Drive and the owner's own computer.
  • The sign-in token is stored only on that computer.
  • No data is collected by, sent to or stored on any other server.
  • No data is shared with, sold to or used by third parties, and none is used for advertising.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
